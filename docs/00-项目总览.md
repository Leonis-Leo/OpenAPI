## 项目信息

- 项目名：OpenAPI 开放平台
- 定位：API 开放平台，对外提供签名鉴权后的统一接口调用能力
- 仓库：`https://github.com/Leonis-Leo/OpenAPI`（分支 `feature_dev`）
- 本地目录：`E:\MyProject\OpenAPI`

| 分类 | 内容 |
| --- | --- |
| 语言 / 框架 | Java 17、Spring Boot 3.3.5、Spring Cloud Gateway |
| 存储 | MySQL 8（本机）、Redis 5.0.14（本机 `E:\redis`） |
| 接口文档 | OpenAPI 3.0 / springdoc（`http://localhost:8101/swagger-ui.html`） |
| 端口 | 网关 8080、后端 8101、MySQL 3306、Redis 6379 |

## 常用命令

```powershell
# 启动后端 / 网关
java -jar openapi-backend\target\openapi-backend-0.0.1-SNAPSHOT.jar
java -jar openapi-gateway\target\openapi-gateway-0.0.1-SNAPSHOT.jar

# 连接 Redis
E:\redis\redis-cli.exe -h 127.0.0.1 -p 6379
```
