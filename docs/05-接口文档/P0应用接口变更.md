# P0 应用接口变更说明

日期：2026-08-08

## 接口变更

- `POST /v1/app/create` 不再接收 `userId`，用户身份从当前登录态获取。
- `GET /v1/app/list` 不再接收 `userId`，只返回当前登录用户的应用。
- `GET /v1/app/debug-list` 仅供当前用户在线调试使用，返回调试所需的完整密钥。
- `GET /v1/app/admin-list?userId=...` 仅限管理员查看指定用户的脱敏应用列表。
- 普通应用列表响应只返回 `secretKeyHint`；完整 `secretKey` 仅在创建/重置响应或明确的在线调试接口中返回。
- 创建应用和重置密钥响应仍返回完整 `secretKey`，前端应提示用户立即保存。

旧的 `docs/05-接口文档/接口文档.md` 和 `openapi.json` 是历史生成快照，重新启动后端访问 `/v3/api-docs` 可生成最新规范。
