# 接口文档

> 自动导出自后端 OpenAPI 规范（`http://localhost:8101/v3/api-docs`），对应文件 `openapi.json`

## 接口列表

| 方式 | 路径 | 说明 | 参数（示例） |
| --- | --- | --- | --- |
| POST | `/v1/user/register` | 用户注册 | userAccount = admin(query/必填), userPassword = admin(query/必填), userName = 管理员(query/可选) |
| POST | `/v1/user/login` | 用户登录 | userAccount = admin(query/必填), userPassword = admin(query/必填) |
| POST | `/v1/interface/subscribe` | 订阅接口 | interfaceId(query/必填), appId(query/必填) |
| POST | `/v1/interface/online` | 接口上线（管理员） | id(query/必填) |
| POST | `/v1/interface/offline` | 接口下线（管理员） | id(query/必填) |
| POST | `/v1/interface/approve` | 订阅审批（管理员） | id(query/必填), approved = True(query/必填) |
| POST | `/v1/app/create` | 创建应用（生成密钥） | appName = 我的应用(query/必填), userId = 1(query/必填) |
| POST | `/api/demo/echo` | 参数回显 | params = hello=world(query/必填) |
| GET | `/v1/interface/{id}` | 查询接口详情 | id = 1(path/必填) |
| GET | `/v1/interface/subscribes` | 订阅审批列表（管理员） | status(query/可选) |
| GET | `/v1/interface/my-subscribes` | 我的订阅列表 | (/可选) |
| GET | `/v1/interface/list` | 查询已上线接口 | (/可选) |
| GET | `/v1/app/list` | 查询用户的应用列表 | userId = 1(query/必填) |
| GET | `/api/demo/name` | 随机名称 | prefix = Hi-(query/可选) |
