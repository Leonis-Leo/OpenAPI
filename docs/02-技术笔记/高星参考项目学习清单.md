# 高星参考项目学习清单

> 数据来源：GitHub API 实时查询（2026-08），完整榜单见 `E:\MyProject\OepnAPI-study\OpenAPI-网关-开放平台-高星项目参考.md`

## 3. 学习顺序（对齐当前阶段）

当前 MVP 已到签名鉴权，下一步是「网关限流 + 统计」：

1. **签名鉴权 → NEAZE/open-platform**：补 OAuth2 授权码流程，AK/SK 是其中一种认证方式。
2. **网关限流 → apache/shenyu**：插件化 + Redis 限流的 Java 现成写法。
3. **接口管理/文档 → ApiManager(CRAP)**：表结构、文档导出、在线调试。
4. **能力规划 → 对照 WSO2 APIM** 功能清单。
