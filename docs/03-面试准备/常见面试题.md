# 常见面试题（OpenAPI 项目）

## 签名鉴权

**Q：为什么用 HMAC-SHA256 而不是 MD5？**

HMAC 带密钥，MD5 是纯哈希无法防止篡改；SHA256 相比 MD5 更安全。密钥只有双方知道，攻击者无法伪造签名。

**Q：如何防止重放攻击？**

时间戳校验（5 分钟窗口）+ nonce 一次性使用（Redis 记录，过期自动清理）。时间戳防"旧请求重放"，nonce 防"窗口内重放"。

**Q：为什么用常量时间比对？**

`MessageDigest.isEqual` 避免因字符串比较短路导致的时间侧信道攻击。

## 架构

**Q：网关和后端各做了什么校验？**

网关负责入口：签名头完整性、时间戳、后续限流；后端负责核心：密钥查询、nonce 防重放、签名比对。网关转发后后端仍校验，防止绕过网关直连后端。

**Q：为什么调用统计要用消息队列异步？**

调用频率高，同步写库会拖慢接口响应并造成数据库压力；MQ 削峰 + 解耦，统计失败不影响主链路。

## Redis

**Q：限流为什么用 Lua 脚本？**

Redis 命令是单条原子的，多条命令组合（检查+扣减）需要 Lua 保证原子性，避免并发下超卖。

**Q：缓存穿透/击穿/雪崩的区别？**

穿透：查不存在的数据；击穿：热点 key 过期瞬间大量请求打库；雪崩：大量 key 同时过期。
