# 部署指南

## 前端构建

```bash
cd openapi-web
npm install
npm run build        # 产物输出到 openapi-web/dist/
```

## Nginx 配置

```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /var/www/openapi-web/dist;
    index index.html;

    # 前端 history 路由回退（否则刷新页面 404）
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 管理后台接口（JWT 走 HttpOnly Cookie，保持同源）
    location /v1/ {
        proxy_pass http://127.0.0.1:8101;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # 签名调用接口
    location /api/ {
        proxy_pass http://127.0.0.1:8101;
        proxy_set_header Host $host;
    }
}
```

## 后端启动

```bash
java -jar openapi-backend/target/openapi-backend-0.0.1-SNAPSHOT.jar
```

依赖：MySQL（`openapi` 库，`db/init.sql` 初始化）、Redis、RabbitMQ。

## 说明

- 登录 token 通过 **HttpOnly Cookie（`openapi_token`）** 传递，前端 JS 读不到，降低 XSS 窃取风险
- 前后端**同源部署**（同一域名/端口走 Nginx 反代）即可免 CORS 配置
- 若前后端跨域部署，需在后端开启 CORS，并把 Cookie 设为 `Secure` + `SameSite=None`，且登录接口显式返回 `Set-Cookie`
- 容器化部署可用 `docker-compose` 扩展（前端 nginx 镜像 + 后端 + MySQL/Redis/RabbitMQ），按需补充
