# P0 本轮完成记录

日期：2026-08-08

本轮已完成并验证：

- SecretKey 重置要求输入当前登录密码，避免仅靠前端确认。
- Redis nonce 防重放改为故障拒绝，Redis 不可用时返回 503。
- 登录失败保护：同一账号 15 分钟窗口最多 5 次失败，触发 15 分钟锁定。
- JWT 注销：退出登录后 token 写入 Redis 黑名单，后续请求返回 401。
- CSRF：登录签发 `openapi_csrf` Cookie，所有 `/v1/**` 写请求要求 `X-CSRF-Token` 双提交校验。
- 数据库、Redis、RabbitMQ、JWT 和 Cookie 配置支持环境变量覆盖。
- 增加 `audit_log` 表、MyBatis 映射和 `/v1/**` 操作审计拦截器，敏感参数不写入日志。
- 一键启动脚本优先使用 JDK 17，修复 E 盘旧 Java 版本导致后端启动失败的问题。

验证结果：后端 Maven 打包通过；前端 `npm.cmd run build` 通过；登录、应用列表、CSRF、注销后 401、审计记录均已联调通过。
