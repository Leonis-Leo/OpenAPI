# OpenAPI 本地开发启动信息

> 仅供本机开发/演示使用。文档中的密码和 JWT 密钥均为当前本地配置，不可直接用于生产环境。

## 一键启动

在项目根目录执行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\start-all.ps1
```

代码变更后需要重新打包时：

```powershell
.\scripts\start-all.ps1 -Build
```

脚本会按 E 盘实际安装路径启动 MySQL、Redis、RabbitMQ、业务后端、网关和前端；已经监听的服务会自动跳过。运行日志位于项目根目录 `runtime-logs`。

## 注意事项

- 前端管理请求直接代理到后端 `8101`；对外签名调用应走网关 `8080`。
- MySQL Windows 服务若因权限无法启动，脚本会直接使用 `E:\MySQL8\my.ini` 启动数据库进程。
- `OPENAPI_COOKIE_SECURE` 本地 HTTP 默认为 `false`；生产环境必须设置为 `true` 并使用 HTTPS。
- 普通应用列表不返回完整 SecretKey，在线调试和点击眼睛查看时才按需获取。
