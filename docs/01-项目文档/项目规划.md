# 项目规划与现状

> 记录 OpenAPI 开放平台已完成的工作与后续规划，保持进度可追溯。

## 已完成

### 项目骨架（Maven 多模块）

- `openapi-common`：签名工具（HMAC-SHA256）、统一响应体、错误码、密钥生成
- `openapi-sdk`：调用方 SDK，自动生成签名请求头
- `openapi-backend`：用户/应用/接口管理 + 签名校验拦截器 + 演示接口
- `openapi-gateway`：Spring Cloud Gateway 统一入口，路由 `/api/**`

### 核心业务

- 用户注册/登录（SHA-256 密码，待升级 BCrypt）
- 应用管理：创建应用自动生成 AccessKey/SecretKey
- 接口管理：已上线接口列表/详情
- 签名鉴权全链路：时间戳防过期 + nonce 防重放（Redis）+ 常量时间比对，网关/后端双层校验
- MyBatis-Plus 时间字段自动填充

### 基础设施

- `docker-compose`（MySQL 8 + Redis 7）、`db/init.sql`（建表 + 演示数据）
- 本机环境：MySQL 8.0.36（已建表）、Redis 5.0.14（`E:\redis`）

### 接口文档

- springdoc / OpenAPI 3.0（`http://localhost:8101/swagger-ui.html`）
- 导出 `openapi.json`（带参数示例）+ Markdown，见 [[05-接口文档/接口文档]]

### CI/CD 自动化测试（已全绿）

- GitHub Actions：Maven 构建 → MySQL/Redis 服务 → 导出 OpenAPI → Apifox CLI 跑 8 个接口用例 → 报告归档
- 前置签名脚本与三个 GitHub Secrets 已配置，详见 [[CI自动化测试]]
