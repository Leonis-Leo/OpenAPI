# OpenAPI

基于 OpenAPI 规范的 API 开放平台项目，为开发者提供统一的接口浏览、申请、调试与调用能力。

## 项目简介

OpenAPI 是一个 API 开放平台（API Open Platform）。平台统一管理对外提供服务的接口，开发者可以浏览接口文档、申请调用权限，并通过平台提供的签名鉴权机制安全地调用接口；平台侧负责接口的发布、上下线、密钥管理与调用统计等能力，让业务系统能够以标准化、可管控的方式对外提供服务。

## 功能规划

- 接口管理：接口的创建、发布、下线与版本管理
- 接口文档：基于 OpenAPI 3.0 规范的接口文档浏览与调试
- 开发者中心：开发者注册、应用管理与密钥（AccessKey / SecretKey）管理
- 签名鉴权：请求签名、防重放与权限校验
- 调用统计：接口调用量、成功率与错误码等指标统计

## 技术选型（规划）

- 后端：Java、Spring Boot
- 接口规范：OpenAPI 3.0 / Swagger
